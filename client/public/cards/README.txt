DUGOUT DECK - CARD PICTURES
===========================

Put the picture for each card in THIS folder (client/public/cards/).
File name = the card code below, in capital letters: STRIKER.webp (or .png / .jpg).
Keep only ONE file per card (delete the old .png when you add a .webp).

Format: WebP (quality 80-85) - or PNG/JPG.
Size:   600 x 840 px (portrait 5:7), up to ~150 KB.
Picture only, no text - the game writes the card name under the picture.
Keep the bottom ~18% and the top-left corner free of important details
(name bar and icon). Template for Photoshop: docs/card-template-600x840.png
A card without a picture keeps its icon.

[x] = picture already in this folder   [ ] = still missing
