DUGOUT DECK - CARD PICTURES
===========================

Put the picture for each card in THIS folder (client/public/cards/).
File name = the card code below, in capital letters, e.g. STRIKER.png

Format: PNG or WebP (JPG is fine without transparency).
Size:   portrait 5:7, e.g. 500x700 or 750x1050 px, up to ~300 KB.
Picture only, no text - the game writes the card name itself.
A card without a picture keeps its current icon.
Card back (optional): BACK.png

After adding pictures, rebuild the desktop game with scripts/publish-desktop.ps1.
(Showing the pictures in the game comes with version 1.1.)
