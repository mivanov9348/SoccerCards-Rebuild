DUGOUT DECK
===========

A football card game for one player.

HOW TO START
  Double-click DugoutDeck.exe. Nothing else needs to be installed (Windows 10 or 11).
  New to the game? Choose "Play the tutorial" in the main menu.

CONTROLS
  Mouse - everything.   F11 - fullscreen.   M - sound on/off.

YOUR SAVES
  %LOCALAPPDATA%\DugoutDeck\dugout-deck.db
  (paste that path into the Explorer address bar). The game saves after every action.
  When an update changes the save format, a backup copy (dugout-deck.db.backup-...) is made first.

NAME PACKS
  All clubs are fictional. Settings -> Name packs imports a pack (a .json file) that renames clubs, leagues and cups.
  Make your own from name-pack-template.json (in this folder); see name-packs.md.
  Packs are kept in %LOCALAPPDATA%\DugoutDeck\name-packs and survive updates.

UPDATING
  Replace the game folder with the new version. Your saves are kept (they are not in the game folder).

UNINSTALLING
  Delete the game folder. To also delete your saves, delete %LOCALAPPDATA%\DugoutDeck.

PROBLEMS?
  If the game does not start, there is an error.log in %LOCALAPPDATA%\DugoutDeck - please send it with your bug report.

All clubs, leagues and cups in the game are fictional. Open-source licences: THIRD-PARTY-NOTICES.txt.
