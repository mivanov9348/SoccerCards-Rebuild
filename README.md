# Dugout Deck — v1.0.0

Футболна игра с карти за един играч срещу компютъра. Цялата игра е на английски. Вдъхновена е от ретро картовите футболни игри, а отгоре има собствен слой с колекция карти и тактика.

**Мачът.** Всяко полувреме е решетка 5×5 с карти с гръб нагоре, всички с еднакъв сив гръб:
- 16 неутрални карти;
- по 4 карти на всеки отбор (виждате само къде са вашите, компютърът знае само своите);
- **Half Time** в първото полувреме и **Full Time** във второто.

Който е на ход, обръща карта и тя остава обърната до края на полувремето. Който обърне карта на отбор, получава ефекта ѝ: своя карта работи за вас, а чужда я **открадвате** (освен Offside Trap). Своите карти се обръщат най-много по една на ход. Подсказките до редовете и колоните казват колко опасни неутрални карти има още там.

Голове идват от няколко места: Goal, Penalty (мини игра с лента за момента на удара), корнер, свободен удар, Голяма възможност след 3 поредни паса и картите на отборите. Преди мача всеки отбор сглобява **тактика** с тактически точки: карти на терена, карти в ръка и тайни модификатори.

**Кариера:**
- 35 лиги от 25 държави: десет държави с по две дивизии и още 15 с по една;
- 10 национални купи и три европейски турнира по 32 отбора;
- пари, награди с карти, колекция, Store и подобрения на клуба;
- борд, оферти и уволнения.

Всички останали мачове се играят на заден план по същите правила.

**Още:** мач за обучение, треньор за първата тактика, пауза на полувремето, три нива на трудност, анимации, генерирани звуци и музика, собствени SVG икони, цял екран (F11). Всички отбори, лиги, купи и стадиони са **измислени** (виж „Имената“ по-долу).

## Технологии

| Част | Технология |
|---|---|
| Клиент | React 19 + TypeScript + Vite (`client/`) |
| Сървър | C# / ASP.NET Core, .NET 10 (`server/DugoutDeck.Api`) |
| Настолна версия | Photino + WebView2 (`server/DugoutDeck.Desktop`) |
| База данни | EF Core + SQLite (`dugout-deck.db`), обновява се с миграции (`Data/Migrations`) |
| Тестове | xUnit (`server/DugoutDeck.Tests`): правила, баланс с 4000 мача, записи, трудност |

## Изисквания

- [.NET SDK 10](https://dotnet.microsoft.com/download)

## Стартиране като едно приложение (най-лесно)

```bash
cd client
npm install
npm run build
cd ../server/DugoutDeck.Api
dotnet run
```

Отворете http://localhost:5080.

## Режим на разработка (промените в интерфейса се виждат веднага)

Терминал 1:

```bash
cd server/DugoutDeck.Api
dotnet run
```

Терминал 2:

```bash
cd client
npm run dev
```

Отворете http://localhost:5173. Ако сървърът е на друг порт (PowerShell): `$env:API_URL="http://localhost:5090"; npm run dev`.

## Настолна версия (Windows)

```powershell
powershell -ExecutionPolicy Bypass -File scripts\publish-desktop.ps1
```

Резултат:
- `dist\DugoutDeck-win-x64\DugoutDeck.exe` – готовата папка, с `README.txt` за играча и `THIRD-PARTY-NOTICES.txt`;
- `dist\DugoutDeck-1.0.0-win-x64.zip` – архив от около 50 MB (за itch.io или за пращане).

Пакетът съдържа .NET, така че на играча не му трябва нищо друго. Записите са в `%LOCALAPPDATA%\DugoutDeck\dugout-deck.db`. Ако нещо се счупи при стартиране, там се появява `error.log`.

- **Версията** се сменя на едно място: `server/Directory.Build.props` (`<Version>`). Показва се в главното меню, в About и в името на архива.
- **Иконата** на програмата се рисува от `scripts/make-icon.ps1`.

## Тестове

```bash
cd server
dotnet test
```

Минават 21 теста. Тестът `Balance_AroundFourGoals_StrongTeamWinsMoreOften` симулира 4000 мача и отпечатва средните голове, откъде идват, колко са кражбите и колко силен е Offside Trap. Ползвайте го при всяка промяна на числата.

## Имената: къде да ги промените

Всички имена са измислени. Всеки клуб се казва по **основния си цвят и града** (напр. „Red Sofia“, „Blue Sofia“, „Green Razgrad“, „Sky Blue Manchester“, „White Madrid“). Ако два клуба от един град имат един цвят, вторият получава двата си цвята („Red-Black Sofia“). Ако и това е заето, името е измислено, без асоциация („Iskra Sofia“). Ако някое име не ви харесва, има два начина.

**1. Във файла `server/DugoutDeck.Api/Data/Seed/seed.json`.** Всеки отбор е на един ред:

```json
{"code": "BG1-01", "name": "Green Razgrad", "short": "GRA", "city": "Razgrad", "stadium": "Razgrad City Stadium", "colors": ["#0b7a3b", "#ffffff"], "ratings": [82,82,80]}
```

- Сменете `name`, `short` (2–4 букви), `stadium`, `city`, цветовете или рейтинга.
- **Не пипайте `code`** – по него играта разпознава отбора.
- Имената на лигите са в `"name"` на всяка лига, купите са в `"cups"`, европейските турнири в `"competitions"`.
- При следващото пускане промените се прилагат **във всички записи**, включително в започнатите кариери. Изключение са отборите, които сте променили в редактора на играта.
- За настолната версия след промяна пуснете отново `scripts\publish-desktop.ps1`.

**2. В играта: Team & league editor.** Промяната важи само за текущата база. Отборът се отбелязва като „редактиран“ и `seed.json` вече не го презаписва.

## Данни и разширяване

- **Нов отбор или лига:** добавете ги в `seed.json` с нов уникален `code`. Добавят се при следващото пускане, а в старите кариери от следващия сезон.
- **Карти:** цените, тактическите точки, рядкостта и броят неутрални карти са в секцията `cards` на `seed.json`. Ефектите са в `Game/MatchEngine.cs`.
- **Шансове:** всички проценти са в `Game/Rules.cs`.
- **Промяна на базата (за разработчици):** променете класовете в `Data/Entities`, после от папка `server`:
  ```bash
  dotnet tool restore
  dotnet ef migrations add ИмеНаПромяната --project DugoutDeck.Api --output-dir Data/Migrations
  ```
  При следващото пускане играта прави резервно копие на записа (`dugout-deck.db.backup-<дата>`) и прилага миграцията.
- **Нова база:** за да започнете на чисто, изтрийте `dugout-deck.db`.

## Бележки

- Емблемите се генерират от цветовете на клуба, звуците и музиката от кода. Играта не съдържа чужди логота, снимки или записи.
- Рейтингите са приблизителна игрова оценка.
- Лицензите на ползваните библиотеки са в `THIRD-PARTY-NOTICES.txt` и в екрана About.
