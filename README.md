# Dugout Deck ⚽🃏

Футболна игра с карти за един играч срещу компютъра. Цялата игра е на английски. Вдъхновена е от ретро картовите футболни игри, а отгоре има собствен слой с колекция карти и тактика.

**Мачът.** Всяко полувреме е решетка 5×5 с карти с гръб нагоре:
- 16 сиви (неутрални) карти;
- по 4 карти на всеки отбор с гръб в цветовете на клуба;
- **Half Time** в първото полувреме и **Full Time** във второто.

Който е на ход, обръща карта и тя остава обърната до края на полувремето. Подсказките до редовете и колоните казват колко опасни сиви карти има още там.

Голове идват от няколко места: Goal, Penalty (мини игра с лента за момента на удара), корнер, свободен удар, Голяма възможност след 3 поредни паса и картите на отборите. Преди мача всеки отбор сглобява **тактика** с тактически точки: карти на терена, карти в ръка и тайни модификатори.

**Кариера:**
- топ 5 първенства и България, всяко с две дивизии, изпадане и промоция;
- национални купи и три европейски турнира по 32 отбора;
- пари, награди с карти, колекция, Store и подобрения на клуба;
- борд, оферти и уволнения.

Всички останали мачове се играят на заден план по същите правила.

- Пълните правила (на английски): [docs/rules.md](docs/rules.md)
- **Как да проверите всичко стъпка по стъпка:** [docs/testing-guide.md](docs/testing-guide.md)

## Технологии

| Част | Технология |
|---|---|
| Клиент | React 19 + TypeScript + Vite (`client/`) |
| Сървър | C# / ASP.NET Core, .NET 10 (`server/FootballCards.Api`) |
| Настолна версия | Photino + WebView2 (`server/FootballCards.Desktop`) |
| База данни | EF Core + SQLite (`dugout-deck.db`, създава се автоматично) |
| Тестове | xUnit (`server/FootballCards.Tests`): правилата на картите и баланс с 4000 симулирани мача |

## Изисквания

- [.NET SDK 10](https://dotnet.microsoft.com/download)
- [Node.js](https://nodejs.org/) 20 или по-нов

## Стартиране като едно приложение (най-лесно)

```bash
cd client
npm install
npm run build
cd ../server/FootballCards.Api
dotnet run
```

Отворете http://localhost:5080.

## Режим на разработка (промените в интерфейса се виждат веднага)

Терминал 1:

```bash
cd server/FootballCards.Api
dotnet run
```

Терминал 2:

```bash
cd client
npm run dev
```

Отворете http://localhost:5173. Ако сървърът е на друг порт (PowerShell): `$env:API_URL="http://localhost:5090"; npm run dev`.

## Настолна версия (Windows)

```powershell
powershell -ExecutionPolicy Bypass -File scripts\publish-desktop.ps1
```

Резултат:
- `dist\DugoutDeck-win-x64\DugoutDeck.exe` – готовата папка (за Steam се качва именно тя);
- `dist\DugoutDeck-win-x64.zip` – архив от около 50 MB (за itch.io или за пращане).

Пакетът съдържа .NET, така че на играча не му трябва нищо друго. Записите са в `%LOCALAPPDATA%\DugoutDeck\dugout-deck.db`. Ако нещо се счупи при стартиране, там се появява `error.log`.

## Тестове

```bash
cd server
dotnet test
```

Тестът `Balance_AroundFourGoals_StrongTeamWinsMoreOften` симулира 4000 мача и отпечатва средните голове, откъде идват и колко често силният отбор бие слабия. Ползвайте го при всяка промяна на числата.

## Данни и разширяване

- **Отбори и лиги:** през *Team & league editor* в играта или в `seed.json`. В компактния формат всеки отбор е `[име, съкращение, град, стадион, цвят1, цвят2, рейтинг]`. Липсващите отбори се добавят при стартиране на сървъра.
- **Карти:** цените, тактическите точки, рядкостта и броят неутрални карти са в секцията `cards` на `seed.json` и се синхронизират при всяко стартиране. Ефектите са в `Game/MatchEngine.cs`.
- **Шансове:** всички проценти са в `Game/Rules.cs`.
- **Нова база:** за да започнете на чисто, изтрийте `dugout-deck.db`. Старите `soccer-cards.db` и `football-cards.db` от предишни версии вече не се ползват.
- **SQL Server/PostgreSQL:** добавете пакета на доставчика и разкоментирайте реда в `GameServer.cs`.

## Бележки

- По време на разработката всички имена са реални (отбори, лиги, купи). Преди продажба трябва да се сменят с измислени.
- Отборите са по състава за сезон 2025/26. Рейтингите са приблизителна игрова оценка.
- Емблемите се генерират от цветовете на клуба. Играта не използва реални логота.
